# 万象奔策：本地 Streamlit 演示

本前端基于仓库提交 `2e4694746ffbca1980e248794ee1d72da6a5d88d` 的后端与样例制作。
直接读取本地 JSON，复用 `TopicAPI` 的纯 Python 查询、原文定位和权重计算。
不需要启动 `serve_api.py`、不需要先前的 FastAPI 网关，也不需要 DeepSeek 密钥。
没有修改后端研判算法或原始运行快照。

## Windows 第一次运行

解压项目，在包含 `start_demo.py`、`backend`、`frontend`、`artifacts` 的文件夹中打开 PowerShell。
建议使用 Python 3.10 或更新版本，并创建独立环境，避免 Anaconda 现有依赖冲突。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-compile -r frontend/requirements.txt
.\.venv\Scripts\python.exe start_demo.py
```

浏览器打开 http://127.0.0.1:8501 。保持 PowerShell 窗口运行，按 Ctrl+C 停止。
无需运行 Activate.ps1，因此不受 PowerShell 脚本执行策略影响。

以后可双击根目录的 `start_demo.bat`。它优先使用项目 `.venv`。
如果端口被占用：

```powershell
.\.venv\Scripts\python.exe start_demo.py --port 8511
```

此时打开 http://127.0.0.1:8511 。安装依赖需要联网；安装后本地展示无需联网。
“打开来源网页”是用户主动跳转外网的可选按钮，不影响离线展示。
Streamlit 使用统计已关闭；页面没有外部字体、图片或 CDN 依赖。

## 三分钟演示路线

1. 左侧选择 `q_001`，展示原始结论、启发式有效分及样例规模。
2. 在“证据溯源”点击 `F0002`，展示事实描述、来源和黄色原文引用；展开完整原文。
3. 切换证据范围到“直接冲突”，点击另一条证据，说明不同时间或口径的差异。
4. 切换“双角色与仲裁”，展示两个角色的独立意见、采用情况、冲突、保留意见和重新评估条件。
5. 切换“依赖图谱”，点击圆点查看关联证据，或使用下方节点选择框；点击关联证据返回原文。
6. 切换“权重预览”，选择 `F0002`，输入 `0` 并点击“应用预览”。该样例 q_001 分数从约 65.17 变为 63.69，并提示需重新审阅。
7. 切换回其他工作区，展示预览值保持一致；最后点击“恢复全部基线”。

## 四个工作区

- **证据溯源**：按问题范围筛选，搜索 ID、事实描述、原文与来源；原文高亮、整篇文档、结构化字段、引用关系和单条证据下载。
- **双角色与仲裁**：分别展示角色原结论及局限，保留采用理由、冲突处理与重启条件；证据按钮可跳转到原文。
- **依赖图谱**：只展示当前问题的全部上游子图；分为来源、段落、证据、中间判断和最终结论。点击圆点联动详情，也提供键盘可用的选择框。红色虚线是冲突，边从左向右，不表示因果。
- **权重预览**：调整证据或判断的有效分，支持多项覆盖、跨问题保留、单项恢复、全部恢复和下载。与后端使用同一公式，不重新调用模型。

## 数据与状态约定

默认样例位置：`artifacts/full_topic_ai171/run_01/`。
也可以在左侧“本地数据设置”中输入另一份完整运行目录，点击“载入本地快照”。相对路径以项目根目录为基准。

| 文件 | 用途 |
| --- | --- |
| input_manifest.json | 问题、完整文档、段落字符区间 |
| evidence_index.json | 唯一证据 ID、引用原句、事实描述与来源组 |
| arbitration.json | 双角色、最终结论、冲突记录、采用情况 |
| source_analysis.json | 来源分组和分组规则 |
| run.json | 运行信息与模型标识 |

读取缺文件、JSON 不合法或引用无法定位时会明确报错，不会偷偷显示假数据。
原文逐字保留并进行 HTML 转义；高亮按段落区间和引用位置计算，不对全文做全局替换。
同一引用在同段出现多次时，沿用后端“第一个匹配”的规则，并给出提示。

文件修改时间、大小及后端代码版本参与缓存键。更新快照后，下一次页面交互会重新加载并清除旧预览。
如果外部程序故意保留同样的文件大小和修改时间，可通过 Streamlit 菜单清缓存或重启服务。
源 JSON 始终只读。权重覆盖保存在当前会话；切换问题保留，切换快照清空。
刷新或断开会话可能清空预览，请先下载需要保存的结果。下载文件不自动回写或导入。

## 表达边界

结论是保存的模型输出，不是经过本前端确认的真实事件结论。
两角色使用同一基础模型；来源分组只是规则估计。
启发式有效分不是正确概率，图谱不是因果证明。
权重重算不改写结论文字；需要审阅的判断会明显提示。
页面没有承诺所有交互都在固定毫秒数内完成；本地数据处理、浏览器渲染和完整交互延迟应分别评估。
